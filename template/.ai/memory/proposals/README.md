# Proposals

Improvement proposals produced by the `team-analyst` (dated
`YYYY-MM-DD.md`), and the build notes the `skill-builder` appends after
executing the ones you approve.

- Proposals are **evidence-backed suggestions, never auto-applied.** Every
  change to an agent, skill, or standard goes through your explicit approval —
  see the `retrospective` playbook.
- Each proposal names its target file, quotes the exact text to add, and states
  its evidence (which run records, how many recurrences).
- Executed proposals are marked with what was built and where; rejected ones
  stay on file so the analyst doesn't re-propose them.
